# NovaMart — E-Commerce Product Filter & Catalog

Modern React (Vite + Tailwind CSS) product catalog with a responsive filter drawer.

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```

## Structure

- `src/components/Navbar.jsx` — sticky header + Filter trigger
- `src/components/ProductGrid.jsx` — responsive product cards
- `src/components/FilterModal.jsx` — filter drawer/modal
- `src/data/products.js` — mock catalog data
